A native desktop chat client for OpenRouter AI models built with Rust and egui.

## Features

- Native desktop GUI with cross-platform support
- Access to 300+ AI models through OpenRouter
- Multi-chat management with folder organization
- Export conversations to Markdown
- Persistent local storage

## Installation

Prerequisites: Rust and an [OpenRouter API key](https://openrouter.ai/)

```bash
git clone https://github.com/your-username/overlook.git
cd overlook
cargo run
```

## Usage

1. Enter your OpenRouter API key in the sidebar
2. Select an AI model from the dropdown
3. Create a new chat and start your conversation
4. Use folders to organize chats and export to Markdown
